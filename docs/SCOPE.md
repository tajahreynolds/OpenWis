# Scope


## What This Project Is


An integration layer and documentation set that connects existing open-source
deliberation, narrative, governance, and metrics tools into a single toolkit
called the Wisdom Assembly Starter Kit.


## What This Project Is Not


- Not a new deliberation platform
- Not a new AI model or algorithm
- Not a mobile app
- Not a hosted service (communities self-host)
- Not a replacement for human facilitation
- Not a community engagement program (that is a separate human-led effort)


## In Scope (Phase 1)


- Python integration scripts between Pol.is, NarraFirma, Hypha, and dashboard
- Documentation for setting up and running the toolkit
- A clonable metrics dashboard template
- Synthetic test data and test suite
- CI/CD for the integration scripts
- Contributor onboarding documentation


## Out of Scope (Phase 1)


- Real community assemblies
- Multi-language support
- Integration with Decidim, Consul, or other platforms
- Mobile support
- AI-generated facilitation or moderation
- Automated participant recruitment
- Automated decision-making


## Out of Scope (All Phases)


- Replacing human facilitators
- Replacing human ethical judgment
- Operating assemblies without human oversight
- Collecting or storing real participant data in this repo
